HUD 悬浮窗圆角方案示意

目标：吸顶到屏幕边缘，像屏幕边缘有一个倒立的凸起，每个转弯用圆角过渡

方案 A：圆角胶囊（倒挂药丸）⭐ 推荐

整体是一个胶囊/药丸形状，顶部被屏幕边缘切平。圆角半径 = 高度的一半，顶部自然形成半圆过渡，底部也是半圆收口。

底部完整圆角收口 ← 顶部半圆过渡 → 
  屏幕边缘
  ═══════════════════════════
     ╭──────────────────╮     ← 顶部：圆角半径 = 高度/2，形成完整半圆
    │                    │       被屏幕边缘切平，视觉上是"从屏幕延伸出来的凸起"
    │      HUD 内容       │     ← 两侧：垂直边
     ╰──────────────────╯     ← 底部：完整圆角收口

方案 B：顶部微凹弧 + 底部圆角

顶部两侧有微小的凹弧过渡（从屏幕边缘向内收缩），底部标准圆角。形状像一个底部圆润的梯形。

  屏幕边缘
  ═══════════════════════════
     ╲                    ╱    ← 顶部：两侧微凹弧，从屏幕边缘向内收缩
      │                  │      ← 两侧：垂直边
      │                  │
       ╰────────────────╯      ← 底部：标准圆角

四种方案对比

A: 圆角胶囊（推荐）
B: 顶部凹弧
C: 顶小圆角 + 底大圆角
D: 顶部微凸弧过渡

推荐方案 A 的理由

  • 圆角半径 = 高度的一半（34pt / 2 = 17pt），顶部自然形成半圆过渡
  • 被屏幕边缘切平后，视觉上就是"从屏幕边缘长出来的倒立凸起"
  • 底部完整圆角收口，线条流畅，无直角断裂
  • 收起态和展开态共用同一圆角逻辑，切换时过渡自然
  • 实现最简单：一个 RoundedRectangle(cornerRadius: height/2) 即可
