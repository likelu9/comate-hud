完整规则见 DESIGN.md §7.3。hover：行白 4%→10%、手柄 22%→50%、图标按钮加 12% 命中底并提亮字色（dur.fast 120ms）· pressed：行 10%→14%、tooltip 隐藏、松手打开任务（dur.instant 80ms）· loading：保留 4 行骨位（同高 34pt）、透明度 0.55↔1 呼吸 1200ms、不显示空态 · empty：24pt 占位、面板夹到最小高 132、页脚保留 · error：status.waiting 图标 + 次级软底按钮，①② 隐藏页脚与铃铛；登录失效保留页脚、额度位换登录引导按钮 · drag：手柄 50% + grabbing + 行数读数，高度 1–10 行夹取 · focus：2pt line.focus #00D4AA 环 + 1pt 偏移 + glow.focus 0 0 4px #00D4AA · disabled：整控件 opacity .4，不用灰色替代色。
