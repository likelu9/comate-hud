# Comate Notch 收起态 UI 设计

## 项目概述
重新设计 Comate Notch 悬浮窗的收起态 UI，使其与 MacBook 刘海完美融合。核心目标：
- 左侧：Comate 图标 + 状态指示灯（灰/黄/红/绿）
- 右侧：快速创建任务图标（无文字）
- 适配 MacBook Air/Pro 各分辨率
- 消除 hover 跳动动画
- 内容不被刘海遮挡

## 技术约束
- 刘海尺寸：所有 notch 机型一致（宽约 200pt，高约 34pt）
- 屏幕宽度：MacBook Air 13.6" = 2560pt，MacBook Pro 14" = 3024pt，MacBook Pro 16" = 3456pt
- 窗口层级：statusBar，不抢焦点

## 设计方案

### 收起态布局（核心）
```
┌─────────────────────────────────────┐
│         刘海区域 (200×34)            │
├─────────┬───────────────────┬───────┤
│         │                   │       │
│  [图标+灯]    (留白)         │ [+] │
│         │                   │       │
└─────────┴───────────────────┴───────┘
  左侧 12pt    中间留白         右侧 12pt
```

**左侧（12pt）**：
- Comate 星形图标（紫粉渐变，16×16pt）
- 图标右下角叠加状态灯（6×6pt 圆形）
- 状态灯颜色：灰(#8E8E93)、黄(#FFB800)、红(#FF3B30)、绿(#34C759)

**右侧（12pt）**：
- "+" 图标（SF Symbol，14pt，白色 70% 透明度）
- 点击触发新建任务

**中间留白**：
- 完全透明，不显示任何内容
- 让刘海自然露出，HUD 仅作为"帽檐"装饰

### 状态灯优先级
1. 红色：有等待用户授权/回复/确认的任务，或异常/错误
2. 黄色：有运行中/思考中的任务
3. 绿色：有已完成的任务（最近 5 分钟内）
4. 灰色：全部空闲

### 展开态布局（悬停触发）
保持现有 340×320 任务列表，无需修改。

## 尺寸适配策略
- 收起态窗口宽度：**固定 80pt**（图标 16 + 间距 + 图标 14 + 边距）
- 收起态窗口高度：**固定 34pt**（与刘海等高）
- 展开态窗口宽度：**固定 340pt**
- 展开态窗口高度：**固定 320pt**
- 窗口始终居中于刘海（通过 auxiliaryTopLeftArea/RightArea 计算）

## 动画方案
- hover 展开：延迟 0.3s 后向下展开，使用 spring 动画（response: 0.35, dampingFraction: 0.82）
- 离开收起：立即收起，使用 spring 动画（response: 0.30, dampingFraction: 0.85）
- **关键**：收起态窗口 Y 坐标固定，仅宽度变化，避免上下跳动
